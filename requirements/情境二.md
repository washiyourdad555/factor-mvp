# User Story: 風險調整後動能因子 (Risk-Adjusted Momentum)

## 基本資訊
- **ID**: US-103
- **版本**: Release_2.0
- **狀態**: In Progress
- **優先順序**: High

## User Story 描述

**作為** 策略開發員

**我想要** 計算個股過去 12 個月的累積報酬率，並將其除以日報酬波動度（且略過最近 1 個月）

**以便於** 找出上漲趨勢平穩的強勢股，作為演算法交易的核心進場訊號，而非買入暴漲暴跌的高風險妖股

## 接受標準

1. [ ] 計算區間必須設定為 $t-12$ 個月末至 $t-1$ 個月末（刻意略過當月 $t$，避免短期微結構反轉效應）
2. [ ] 計算報酬率與波動度時，必須一律使用「已還原權息」的每日收盤價
3. [ ] 風險調整後動能 = 區間累積報酬率 ÷ 區間日報酬率年化標準差
4. [ ] 若該股票上市未滿一年（有效交易日低於 200 天），數值標記為缺值 (NaN)

## 相關資訊

**衝突**: 與舊版的純價格動能模組可能會有資源佔用衝突，需分開排程

**依賴**: 依賴 US-012

**備註**: 需注意除權息旺季時的還原股價計算正確性，以防動能失真。
