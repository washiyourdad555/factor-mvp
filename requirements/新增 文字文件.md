# User Story: 盈餘品質因子 (Earnings Quality)

## 基本資訊
- **ID**: US-102
- **版本**: Release_1.2
- **狀態**: Done
- **優先順序**: Critical

## User Story 描述

**作為** 基金經理人

**我想要** 取得最新單季「來自營運之現金流量」與「稅後淨利」的比值

**以便於** 確保投資組合的下檔防禦力，提早避開利用會計作帳但實質上沒有現金流入的地雷股

## 接受標準

1. [ ] 嚴格比對財報實際公布日，只使用公布日小於或等於計算日的財報數據
2. [ ] 盈餘品質比率 = 最新單季來自營運之現金流量 ÷ 絕對值(單季稅後淨利)
3. [ ] 當單季稅後淨利為 0 時，為避免分母為零的錯誤，該期比率強制標記為缺值 (NaN)
4. [ ] 結果必須同時列出對應的財報年季（如 2024Q2），並匯出 CSV 供風控部門稽核
