User Story: 盈餘品質因子 (Earnings Quality)

基本資訊

ID: US-102

版本: Release_1

狀態: In Progress

優先順序: High

User Story 描述

作為 量化研究員

我想要 在任一計算日，取得最新單季「來自營運之現金流量」與「稅後淨利」的比值

以便於 衡量公司的真實盈餘品質，避開利用會計作帳但實際沒有現金流入的虛假獲利公司

接受標準

[ ] 嚴格比對財報實際公布日，只使用公布日小於或等於計算日的財報數據

[ ] 盈餘品質比率 = 最新單季來自營運之現金流量 ÷ 絕對值(單季稅後淨利)

[ ] 當單季稅後淨利為 0 時，為避免分母為零的錯誤，該期比率標記為缺值 (NaN)

[ ] 結果必須同時列出對應的財報年季（如 2024Q2），方便後續回測稽核

相關資訊

衝突: 無

依賴: 需先完成財報數據庫的時點對齊模組

備註: 屬於「品質」類因子，能有效降低踩到地雷股的機率。
