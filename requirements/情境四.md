# User Story: 預估高股息殖利率因子 (Trailing Dividend Yield)

## 基本資訊
- **ID**: US-105
- **版本**: Release_3.1
- **狀態**: In Review
- **優先順序**: Highest

## User Story 描述

**作為** ETF 產品經理

**我想要** 以近四季累積 EPS (TTM) 乘上近一次配息率，再除以每日最新股價來算出預估殖利率

**以便於** 作為高股息 Smart Beta 策略的前篩濾網，確保選股池在未來具備足夠的配息吸引力與行銷亮點

## 接受標準

1. [ ] EPS 必須使用計算日當下「已公布」的近四季財報 EPS 滾動加總 (TTM)
2. [ ] 預估配息率 = 最近一年度實際宣告之普通股現金股利 ÷ 該年度 EPS
3. [ ] 預估殖利率 = (TTM EPS × 預估配息率) ÷ 計算日最新還原收盤價
4. [ ] 若 TTM EPS 為負值，或歷史配息率為 0，則預估殖利率直接標記為 0，直接淘汰

## 相關資訊

**衝突**: 命名可能與既有的歷史固定殖利率欄位混淆，資料表需加上 est_ 前綴字

**依賴**: 依賴 US-030

**備註**: 這是下半年度發行新金融產品的核心指標，審查須盡速通過。
