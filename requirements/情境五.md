# User Story: 單季毛利率年變動因子 (Gross Margin YoY Diff)

## 基本資訊
- **ID**: US-106
- **版本**: Draft_0.1
- **狀態**: Backlog
- **優先順序**: Low

## User Story 描述

**作為** 財務工程師

**我想要** 抓取最新已公布單季毛利率與「去年同季」毛利率的百分點差值

**以便於** 建立基本面轉機的量化特徵，供後續的機器學習模型進行非線性的超額報酬預測

## 接受標準

1. [ ] 只使用公布日小於或等於計算日的財報數據，未到實際公布日不得切換至新一季
2. [ ] 毛利率年變動 = 最新已公布單季毛利率 － 去年同季毛利率
3. [ ] 若營收為 0、財報缺漏，或股票剛上市缺少去年同季資料，則該變動值標記為缺值 (NaN)
4. [ ] 產出特徵需能串接至現有的 ML Pipeline，並支援 Z-score 去極端值處理
