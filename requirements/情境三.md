# User Story: 投信買超佔股本比因子 (ITC Net Buy Ratio)

## 基本資訊
- **ID**: US-104
- **版本**: Beta_0.9
- **狀態**: To Do
- **優先順序**: Medium

## User Story 描述

**作為** 籌碼分析師

**我想要** 在計算日取得過去 5 個交易日「投信買賣超總張數」佔「最新動態發行總張數」的比例

**以便於** 辨識台股特有的「投信作帳認養」行情，提早卡位具備籌碼優勢的中小型股

## 接受標準

1. [ ] 籌碼資料必須使用 $t-1$ 日（含）以前的盤後公布數據，絕不可使用 $t$ 日當天未收盤的籌碼
2. [ ] 買超佔比 = 過去 5 日投信累計買賣超張數 ÷ 計算日當下的發行總張數
3. [ ] 股本（發行總張數）必須對應計算日當下，需考慮增減資變化，不得偷看未來的股本
4. [ ] 若該檔股票過去 5 日內無任何投信交易紀錄，該數值應計算為 0，而非缺值 (NaN)

## 相關資訊

**衝突**: 無

**依賴**: 依賴 US-015 與 US-016

**備註**: 本土色彩濃厚的因子，需特別排除外資假借投信名義進出的 ETF 標的。
